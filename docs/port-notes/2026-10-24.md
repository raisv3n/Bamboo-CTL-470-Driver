# 2026-10-24 — macOS v0.2.0 (first working driver)

Starting point for any port. Behaviour is specified in `docs/protocol.md`; this note records what
was learned getting there, in platform-neutral terms.

## What exists

- macOS driver, tested on macOS 26.6.2 (arm64) with the real CTL-470. Not yet run on macOS 27.
- Golden files in `shared/testdata/` from four real captures; the Swift decoder passes them.

## Lessons that apply to every platform

1. **The tablet must be told to switch modes** (`02 02` feature report). Without it, it's a
   relative mouse with no pressure — this is what "the pen sort of works but badly" looks like.
2. **Re-send the mode after reconnect/wake.** The tablet forgets.
3. **Ignore far-hover packets** (proximity set, ready not set). They produced most of the visible
   cursor jumps when the pen approached or left the surface.
4. **Unfiltered coordinates jitter ~5 units at rest** — smoothing is required, and the One Euro
   parameters in the protocol doc worked well.
5. **Taps wobble ~1 mm.** Without the click snap, taps became tiny drags and double-clicks failed.
   Measure the double-click radius in tablet units.
6. **16:10 tablet on a 16:9 screen** stretches circles; "keep proportions" crop is the default.
7. **Event-injection permission failures are silent.** On macOS, an untrusted process's synthetic
   events are dropped without error, which looked exactly like a mapping bug. Check the permission
   state explicitly at startup and surface it in the UI. Expect the same class of problem on other
   platforms (Windows UIPI with elevated target windows; uinput device permissions on Linux).
8. The upper side switch (`0x04`) never fired on the test pen — don't treat its absence as a port bug.

## Mac-only bits and their equivalents

| macOS | Windows | Linux (if ever needed) |
|---|---|---|
| IOHIDManager + `IOHIDDeviceSetReport` | `HidD_SetFeature` on the digitizer collection / hidapi | hidraw `HIDIOCSFEATURE` / hidapi |
| CGEvent tablet proximity + tablet-point mouse events | `InjectSyntheticPointerInput` (`PT_PEN`) | uinput pen device |
| Accessibility permission | none for same-integrity windows (UIPI blocks elevated ones) | udev rule for `/dev/uinput` + hidraw |
| SMAppService login item | HKCU `...\Run` | XDG autostart `.desktop` |
| NSStatusItem menu | `Shell_NotifyIcon` tray | tray via the desktop's StatusNotifierItem |
| NSWorkspace didWake → re-send mode | `WM_POWERBROADCAST` / device arrival | udev add event |
